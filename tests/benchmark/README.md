# 분석기 문제지·정답지

음원 분석기의 단계마다 "문제지(입력)"와 "정답지(나와야 하는 결과)"를 두고, 분석 결과를 채점한다.
곡은 모두 코드로 직접 만든 것이라 저작권 문제가 없고 정답이 정확하다.

- 저장소에는 곡을 만드는 MIDI와 정답표(answer.json)만 올린다.
- 음원(wav)은 용량이 커서 `output/benchmark/` 에 만든다(올리지 않음).

## A단계: 소리 분리 (`separation_set.py`)

| 문제 | 들어 있는 악기 | 시험하는 것 |
|---|---|---|
| 01_노래와_피아노 | 목소리(vocals) + 피아노(piano) | 이 프로젝트의 주 용도(노래 반주 악보) |
| 02_피아노만 | 피아노(piano) | 없는 트랙(목소리·드럼·베이스)을 '없음'으로 판단하는지 |
| 03_밴드 | 목소리 + 피아노 + 베이스 + 드럼 | 4개 트랙을 모두 나누는지 |

- 문제지: `problem.wav` = 정답 트랙들을 그대로 더한 음원
- 피아노 정답은 피아노 트랙이 있는 모델(htdemucs_6s)에서는 piano, 없는 모델(htdemucs)에서는 other와 비교한다
- 정답지: `answer_<트랙>.wav`(악기별 음원), `answer.json`(있어야/없어야 하는 트랙)
- 점수
  - 닮음(dB): 분리한 트랙이 정답 트랙과 얼마나 같은지. 클수록 좋음(10 이상이면 쓸 만함)
  - 새어나옴(dB): 없어야 하는 트랙에 남은 소리 크기. 작을수록 좋음(-20 이하면 거의 없음)
  - 있다고_판단: 들림 정도로 '이 악기가 있다'고 본 결과가 정답과 맞는지

```bash
uv run python tests/benchmark/separation_set.py build   # 문제지·정답지(음원) 만들기
uv run python tests/benchmark/separation_set.py grade   # Demucs로 분리해 채점(몇 분)
```

주의: 문제의 '목소리'는 진짜 사람 소리가 아니라 사운드폰트의 '우~' 소리다.
Demucs는 진짜 목소리로 배운 AI라 이 소리를 목소리로 잘 못 나눌 수 있다(실제 노래 녹음보다 어려운 문제).

### 채점 결과 (2026-11-22)

| 문제 · 트랙 | htdemucs | htdemucs_6s (기본) |
|---|---|---|
| 노래와_피아노 · 목소리 | 2.4 | **8.4** |
| 노래와_피아노 · 피아노 | -0.5 | **7.3** |
| 피아노만 · 피아노 | 44.0 | 31.9 |
| 밴드 · 목소리 / 피아노 | 2.6 / -2.2 | **8.1 / 4.0** |
| 밴드 · 베이스 / 드럼 | 19.0 / 14.1 | 19.4 / 14.4 |

'있다/없다' 판단: htdemucs 12/12, htdemucs_6s 18/18 (모두 맞음).
처음에는 6s에서 2개가 틀렸다(밴드의 작은 피아노를 '없음', 노래와_피아노의 other를 '있음').
이름 있는 트랙은 -30dB, 6트랙 모델의 other(새어 나온 소리 모음)는 -8dB를 기준으로 바꿔 고쳤다.

## B단계: 박·박자 (`beat_set.py`)

| 문제 | 시험하는 것 |
|---|---|
| 01_4박자_피아노 | 기본 4/4, 8분음표 분산화음 |
| 02_3박자_왈츠 | 3/4 (쿵·짝·짝) |
| 03_8분의6박자 | 6/8 — 점4분음표가 한 박(한 마디 2박) |
| 04_빠르기_변화 | 7~8마디에서 100→70으로 점점 느려졌다가 9마디에 원래 빠르기 |
| 05_못갖춘마디 | 한 박짜리 못갖춘마디로 시작 |
| 06_드럼_밴드 | 드럼·베이스·뒷박 피아노 |

- 정답지 `answer.json`: 박 위치(beats, 초), 마디 첫 박 위치(downbeats, 초), 박자표, 한 마디 박 수, 못갖춘마디 박 수, 빠르기
- 점수: 박_정확도·첫박_정확도(맞힌 비율, ±0.07초 안이면 맞음, 1이 만점), 박자표_맞음, 빠르기

```bash
uv run python tests/benchmark/beat_set.py build
uv run python tests/benchmark/beat_set.py grade
```

## C단계: 음 인식 (`note_set.py`)

- 문제지: B단계 피아노 3곡(4박자·왈츠·6/8) + A단계 여러 악기 2곡(노래+피아노, 밴드). 음원은 A·B단계 build로 만든 것을 다시 쓴다.
- 정답지: `notes/<문제>/answer.json` — 트랙마다 [음높이, 시작(초), 끝(초)]. 곡을 만든 MIDI에서 뽑음.
- 점수: 시작_F1(음높이 같고 시작 ±0.05초), 길이까지_F1(끝 시각도 맞아야 함). 1이 만점.

```bash
uv run python tests/benchmark/note_set.py build
uv run python tests/benchmark/note_set.py grade   # 결과: output/benchmark/notes_채점.json
```

### 채점 결과 (2026-11-22, `analysis/notes.py`)

| 문제 | 트랙 | 시작_F1 | 길이까지_F1 |
|---|---|---|---|
| 피아노 4박자 | 피아노 | 0.97 | 0.672 |
| 피아노 왈츠 | 피아노 | 0.93 | 0.055 |
| 피아노 6/8 | 피아노 | 0.979 | 0.684 |
| 노래+피아노 | 목소리 | 0.848 | 0.727 |
| 노래+피아노 | 피아노 | 0.914 | 0.561 |
| 밴드 | 목소리 | 0.686 | 0.629 |
| 밴드 | 피아노 | 0.827 | 0.327 |
| 밴드 | 베이스 | 0.833 | 0.7 |

약점: 피아노 음 끝(길이)은 소리가 서서히 줄어들어 잘 못 맞힌다.
- 분리한 피아노 트랙은 울림 기준을 낮추고 이어 붙이기를 꺼서 좋아졌다(노래+피아노 0.18→0.56, 밴드 0.10→0.33).
- 왈츠(0.06)는 짧은 화음의 잔향이 0.2초쯤 남아 길게 잡히고, 긴 음은 일찍 끊긴다. 소리만으로는 못 고쳐서
  리듬 정리 단계에서 박 위치에 맞춰 길이를 정할 예정. (음 크기 대비 끊기는 시험했지만 더 나빠져 버림)

## D단계: 리듬 (`rhythm_set.py`)

C단계에서 찾은 음(초 단위)을 B단계의 박에 맞춰 악보에 쓸 위치·길이로 바꾸는지 시험한다.
위치·길이는 4분음표 단위 분수(1 = 4분음표, 1/2 = 8분음표, 1/3 = 셋잇단 8분음표, 3/2 = 점4분음표).

| 문제 | 시험하는 것 |
|---|---|
| 01~05 | B단계 피아노 곡 그대로(4/4, 왈츠, 6/8, 빠르기 변화, 못갖춘마디) |
| 06_리듬_여러가지 | 점음표, 16분음표, 셋잇단, 당김음, 쉼표, 온음표 |

- 정답지: `answer.json`의 notes = [음높이, 위치, 길이]. 곡 정의에서 바로 뽑는다
- 점수: 위치_F1(위치 맞힘), 길이_정확도(위치 맞힌 음 중 길이도 맞힘), 둘다_F1
- 정답_입력(박·음을 정답에서 가져와 리듬 단계만 시험)과 실제_입력(음원 분석 결과로 시험) 두 가지로 채점

```bash
uv run python tests/benchmark/rhythm_set.py build
uv run python tests/benchmark/rhythm_set.py grade
```

### D단계 결과 (위치_F1 / 길이_정확도)

| 문제 | 정답_입력 | 실제_입력 |
|---|---|---|
| 01 4박자 | 1.0 / 1.0 | 0.928 / 0.807 |
| 02 왈츠 | 1.0 / 0.547 | 0.93 / 0.059 |
| 03 6/8 | 1.0 / 1.0 | 0.979 / 0.935 |
| 04 빠르기 변화 | 1.0 / 1.0 | 0.579 / 0.809 |
| 05 못갖춘마디 | 1.0 / 1.0 | 0.935 / 0.921 |
| 06 리듬 여러가지 | 1.0 / 0.969 | 0.925 / 0.744 |

- 피아노 음 끝이 일찍 잡히는 것을 메우려고, 가까운 음역의 다음 음이 1박 안에 오면 그 음까지 늘린다
  (실제_입력 길이 평균 0.42→0.71). 대신 1박보다 짧은 쉼표·짧게 끊는 음(왈츠의 8분 화음)도 늘어난다.
- 약점: 빠르기가 바뀌는 곡은 B단계의 박이 어긋나 위치가 틀린다(0.58). 왈츠의 8분 화음은 소리 여운 때문에
  4분음표로 잡힌다.
